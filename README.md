# BIPproject

BIP实验：皮肤病变分类任务的的代码与数据、结果仓库。

- code： 用于存放所有需要使用的代码
- data：用于存放需要使用的数据集，包括图像和蒙版
- result：存放可视化结果以及必要的额外说明
- deeplearning：请把所有有关于深度学习相关的内容都放在这个文件夹中，包括深度学习部分的训练与测试代码，以及代码说明、测试结果

如果你修改了代码或是仓库中的其他内容，请在下方按照示例格式更新修改记录

data中所有的image和mask都已经做好了归一化。所有的原始图像和mask都是224\*224的
原始图像为RGB图像，部分特征需要使用灰度图像，已经预留了灰度转换的接口可以直接调用
